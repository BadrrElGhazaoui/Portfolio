## Getting Started

### Prerequisites

- Node.js
- npm

### Installation

Clone the repository and navigate to the project directory:

```bash
git clone <your-repository-url>
cd portfolio-clean
npm install
```

### Run Locally

```bash
npm run dev
```

### Build for Production

```bash
npm run build
```

To preview the production build locally:

```bash
npm run preview
```
